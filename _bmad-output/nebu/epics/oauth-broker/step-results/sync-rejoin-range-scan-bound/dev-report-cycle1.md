## Per finding

1. **Empty floor window (MINOR-2 = Kassandra LOW-1).** `db.ex` `rj_floor` is now `CASE WHEN $3 <= 0 THEN NULL ELSE COALESCE(window min, fallback, bigint max) END`. Fallback = `min(origin_server_ts)` of `room_id = $1 AND room_pos > $3 AND room_pos <= $4 ORDER BY room_pos LIMIT 64` (the next 64 events above the base; evaluated only when the window is empty). I used LIMIT 64 instead of LIMIT 1: the same lookback on the other side of the base, so a skewed event among the first 64 new events is still read (a LIMIT 1 floor would lose it; a test pins it). The last resort (largest bigint) is for "no event above the base at all": the answer is empty by construction, and without it `GREATEST` would again ignore a NULL and walk the room. Base 0 keeps "no floor" (pinned by the existing test). `@doc` corrected ("the floor rises" only for a PARTIAL gap; empty window described), 06-runtime and the closure reworded.
