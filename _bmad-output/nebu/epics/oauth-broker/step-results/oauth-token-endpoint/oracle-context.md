# Oracle gate story 3 oauth-token-endpoint (2026-10-10)
## MUSTs
POST x-www-form-urlencoded; code grant params grant_type,code,redirect_uri,client_id,code_verifier; refresh grant_type,refresh_token,client_id. Errors RFC 6749 5.2 never Matrix error; no-store + Pragma no-cache. Every grant issues refresh token; AT short-lived; refresh grant mandatory; PKCE S256; strict redirect match. Response access_token,token_type Bearer,expires_in,refresh_token,scope (REQUEST prefix echo). Rotation SHOULD; old RT remains valid until new AT/RT used (no window); reuse of invalidated RT SHOULD revoke session. Clients: network/5xx => retry with old RT, any 4xx => logged out; so only definitive outcomes may be 4xx; refresh never 429. Device reuse allowed for same user, invalidates all previous AT/RT of device. Expired AT 401 M_UNKNOWN_TOKEN preferably soft_logout:true; destroyed session no soft_logout. RFC 6749 3.2/3.1: empty param = omitted; duplicates invalid; unknown params ignored. Reused code MUST be denied (revoking derived tokens SHOULD). CORS: OPTIONS must not run endpoint logic; Allow-Headers X-Requested-With, Content-Type, Authorization.
