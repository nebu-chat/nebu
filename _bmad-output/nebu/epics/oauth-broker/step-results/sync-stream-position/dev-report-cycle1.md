## 2. Design choices (items 2 / 3 / 4)

- **Item 2 (MEDIUM-1):** fix, no follow-up. The page read is the initial-sync read the story's D9 already names ("for an absent row the visible newest 20, as an initial-sync room"); it is segment-driven (never scans invisible history) and head-bounded (D12 exactness: an event committed after the head read has a higher position and comes with the next delta, whose base is then the head). Statement count unchanged (one read per moved room). The statement timeout stays out (gk (4) conflict, see above).
- **Item 3 (LOW-2):** documented residual, not the conditional insert (reasons above).
- **Item 4 (INFO-3):** CHECK on `class` and `prev_class`, inline in the CREATE TABLE.
