# Test review: sync-stream-position (pre-dev quality gate, story 2 of 2 for `fc`), 2026-10-27

Worktree `open-chat-oauth`, branch `feature/migrate-to-oauth2`, HEAD `e066d6f3`. Read-only review of `git diff --cached -- server/test` (7 new files, 144 tests; 13 amended existing files), the story incl. D20, the ATDD report, the oracle context and `reference-impl.diff` (used only to judge satisfiability / over-pinning). Nothing was run (no DB container touched); all findings come from reading.

Verdict: **MAJOR: 3, MINOR: 10, INFO: 8**

## Summary

The suite is strong and mostly design-independent: real concurrency tests are bounded and self-cleaning, the D18 token-trust tests (foreign device / user, forged `s2_`, A's previous token presented by B, byte-identical other rows) are thorough, the failure direction (fail closed, old token stays valid) is pinned, and the amendments of existing suites are in the main legitimate (behaviour changed by D5/D8/D9/D20) with old -> new comments. Three things block dev: (1) the history-visibility security net (randomised model test, marker / parameter-bound test, cost test) was NOT carried over to the new `/sync` read path although the story names `room/history_visibility_db_test.exs` for amendment; (2) the shared unit fakes pin an undocumented persist API (`persist_sync_position/3` + spec map) in ~110 tests while D20(6) and the ATDD report say the persist is "the implementer's choice / NOT pinned"; (3) the second half of the D8 / D20(1) rule (re-base of rows changed in the generation being replaced, i.e. a SECOND retry with the same previous token) has no test, and a missing re-base is a silent event loss.
