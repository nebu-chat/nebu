SPEC: POST /rooms/{id}/kick|ban|unban: user_id required, reason optional string on the target's m.room.member event (ban/unban Added v1.1); responses only 200 {} and 403 (examples: "kicker/kickee not in the room", "banner not in the room", "power level insufficient"); 404 not listed (D6 Nebu choice); all three "Rate-limited: No", auth required. Every member branch ends in allow/reject: the generic events-level step is never reached. Event <= 65536 bytes, user id <= 255. /forget: joined must leave first, else 400; banned/kicked (not joined) => 200. /upgrade: recommended transfers join_rules + power_levels; membership events SHOULD NOT be transferred (impersonation over federation); old room's power levels SHOULD be lowered.
