Medien / Einstellungen

Medien-Einstellungen

Aufbewahrung

Automatisches Löschen freigegebener Dateien nach Ablauf einer Frist.

Vorbelegt aus Umgebungsvariable beim ersten Laden · zuvor: aus
Betrifft alle freigegebenen Dateien älter als 90 Tage. Diese Änderung löst eine automatische Massenlöschung nie beanstandeter Dateien aus. Bitte bestätigen Sie bewusst.

Lifecycle-Regeln

Geordnete Leiter der Zustandsübergänge — jede Stufe mit eigener Frist.

Freigegeben → nach Tagen → Gelöscht
Gelöscht → nach Tagen → Hard-Delete
Verwaist (orphaned) → nach Tagen → Hard-Delete

Legal-Hold-Dateien sind von jeder Stufe ausgenommen, bis die Sperre über Zwei-Augen freigegeben wird.

Objektspeicher

S3-kompatibler Speicher (on-prem MinIO) für Medien-Binärdaten.

Erreichbar
312 bestehende Dateien liegen im alten Bucket und wären nicht mehr erreichbar. Bitte Daten zuerst kopieren, bevor Sie speichern.

Jede gespeicherte Änderung schreibt einen Audit-Log-Eintrag (media_config_updated / media_storage_config_updated). Geheime Werte werden nie im Klartext protokolliert.
