# Session 2026-06-17 — Media Gateway Migration (Elixir port)

Pipeline oracle-gate for story `media-gateway-migration` (full-elixir-stack epic).
Porting Go media gateway → Elixir Plug. Endpoints: PUT /media/v3/upload,
GET /media/v3/download/{sn}/{id}[/{file}], GET /media/v3/thumbnail, GET /media/v3/preview_url.

## Key spec points reaffirmed (v1.18 §Content repository)
- mxc:// server-authoritative; client media_id untrusted.
- Content-Disposition MUST since v1.12 (inline for safe types, else attachment; filename= when fileName seg).
- CSP sandbox + CORP cross-origin + nosniff SHOULD on download/thumbnail (Epic-12 gap, re-flagged).
- thumbnail params width/height REQUIRED ints, method crop|scale, animated optional.
- preview_url: OG keys og:title/og:description/og:image(mxc) + matrix:image:size; empty → {} not error; auth required.
- Errors: 413 M_TOO_LARGE, 429 M_LIMIT_EXCEEDED, 404 M_NOT_FOUND, 416 range, 400 M_INVALID_PARAM.

## IMPORTANT deviation flag
AC4 "room membership 403 on download" is a **Nebu access-control extension** — Matrix media is
NOT room-scoped in spec. Tests should assert Nebu behavior, not call it spec compliance.
Story targets deprecated /media/v3/ only; authenticated /client/v1/media/ remains open follow-up.

SSRF guard on preview_url is a Nebu security concern (not spec-named) — relevant to Kassandra gate.
