# Session — 2026-06-22

## space-room-in-space-bug — createRoom `initial_state` (SEC Gate 1, story-level)

**Verdict:** APPROVED — 0 CRITICAL, 0 HIGH, 1 MEDIUM (F-1), 2 LOW.
**Report:** `_bmad-output/nebu/step-results/space-room-in-space-bug/security-review-2026-06-22.md`

Bug fix: `POST /createRoom` now replays the Matrix `initial_state` array as creator-authored
state events (new proto field `initial_state_json` → `apply_initial_state/3` → `emit_state_event/5`).

### Findings
- **F-1 MEDIUM** — amplified authenticated DoS: no `initial_state` array-length cap + no rate limit
  on `createRoom`. ~1 MB body → ~40k entries → serial Ed25519-sign + DB-insert + pg-fanout in the
  request process. Recommend per-array cap (≤64) and/or a RateLimit plug on createRoom.
- **F-2 LOW** — deeply-nested client `content` → unbounded recursion in `CanonicalJson.normalize/1`
  → possible 500 + partial room. Pre-exists on generic state-PUT path.
- **F-3 LOW** — no audit_log for initial_state replay (consistent with generic state-PUT; advisory).

### Why the design held (key insight — candidate MEMORY pattern)
The forbidden-types **denylist** (block only create/member/power_levels) is weaker-looking than the
generic state-PUT **allowlist**, but it is SOUND here because **Nebu does not derive membership or
power-levels by folding events out of the DB** — that state is GenServer-authoritative
(`Room.Server.join` / `set_power_levels`). `apply_initial_state` only calls `emit_state_event`
(pure event-writer), never mutating `state.members`/`state.power_levels`. So a forged (or
case-variant `M.Room.Member`) membership/PL event would be inert timeline noise in the creator's
own room. Case/namespace-variance bypass of the denylist → no effect.

Envelope server-built (room_id=new room, sender=creator) → no IDOR/cross-room write.
parent_space guard faithfully mirrors `check_parent_space_membership/2`; identity shapes match
(creator_id = current_user = `@localpart:server`), so ContextKeySub-vs-UserID confusion N/A.
Auth via OidcPlug confirmed. Body bounded 1 MB (JsonBody, /admin carved out).

### MEMORY.md follow-up
Add pattern: "Denylist on a privileged state-write path is sound IFF the authoritative state is
not event-derived." Watch: if a future story makes Nebu reconstruct membership/PL from the event
log (state resolution), this denylist becomes a forgery primitive — re-review immediately.
