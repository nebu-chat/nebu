**Finding summary:** 0 CRITICAL, 0 HIGH, 0 MEDIUM, 0 LOW, 2 INFO (both accepted, non-blocking —

see unfiltered).

("attacker-controlled filenames rendered in the admin origin = stored-XSS risk," flagged
