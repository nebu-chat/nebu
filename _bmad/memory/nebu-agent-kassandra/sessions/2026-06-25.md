## The change
`NEBU_OIDC_ISSUER`/`NEBU_OIDC_AUDIENCE` no longer `raise` at boot — default nil. New
`Nebu.Web.OidcConfig` (`:protected` ETS GenServer, `:pg` cluster invalidation) reads
issuer/audience/jwks_uri from `server_config`. `OidcPlug.oidc_issuer/0`+`oidc_audience/0`:
env first, then `OidcConfig.get()`. Bootstrap wizard gains audience + jwks_uri fields
(env-locked when env set). `JwksCache.refresh/1` added; `http_fetch` falls back to
`OidcConfig.jwks_uri()`.

## Why CLEAN (the key insight)
This is the OIDC fail-open family (#43/#57/#60/#66) — the EXACT class that recurred for
epics — but the implementers closed it by construction across cycles M-1/M-2/C-1/C-2/
MAJOR-1/MINOR-1/C1. Fail-closed is structural, not incidental:
- Both env AND DB nil → `:issuer_not_configured`/`:audience_not_configured` → 401. This is
  the INVERSE of #57.
- OidcConfig ETS table absent/crashed → `read_from_ets` returns all-nil → 401. `load_from_db`
  catches `{:error,_}` (no raise) → boot survives DB-down → all-nil → 401.
- Supervision order verified: Repo → OidcConfig → JwksCache, `:one_for_one`.
- `nilify` trims before nil-check → whitespace value = absent (fail-closed).

## Things I confirmed instead of assumed
- **Seam not attacker-reachable**: `:oidc_config_source` / `:oidc_jwks` /
  `:bootstrap_cache_refresh_hook` all written ONLY in tests; Application env not mutated by
  any endpoint. Grep-verified.
- **No admin-repoints-IdP escalation**: `ConfigLive.save_refresh_mode` whitelists ONLY the
  2 refresh-mode enum keys — does NOT write oidc_issuer/audience/jwks_uri. Those keys written
  exactly once in `bootstrap_completed?`-gated `do_complete_bootstrap`.
- **Bootstrap takeover blocked**: pre-bootstrap anon can fill draft only; completion requires
  verified `bootstrap_sub` + chosen claim ∈ verified token's discovered values (C1 guard);
  session bound to verified sub. `bootstrap_completed?` fails CLOSED on DB error (prior HIGH-1).
- **Open redirect**: `/admin/login?error=auth_failed` is a static literal; `LoginController.index`
  ignores params, serves static HTML — no reflection.

## LOW/INFO carried
- LOW-1: `OidcConfig.refresh/1` public GenServer call (no HTTP route → not reachable; watch if
  a "reload config" admin endpoint is ever added — gate + rate-limit the :pg broadcast).
- LOW-2: matrix_sessions no-RLS carry-over; OidcConfig is a 2nd node-local auth-input cache.
- INFO-1: OidcConfig :pg invalidation broadcast-only, no TTL refresh — fine for write-once value.
- INFO-2: SSL story rides same branch, not reviewed here.

No new MEMORY pattern — team got fail-closed shape right by construction. The good-example
companion to the fail-open family: when a required-config value moves from boot-raise to
runtime-lookup, the lookup default MUST be the reject-causing value (nil → not_configured),
not an empty-but-truthy one.
