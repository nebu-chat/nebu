# Step 1b: Oracle Gate (conditional — Matrix features only)

**Script first, LLM only for the rest.** **Agent:** `@nebu-oracle` | **Model:** opus (agent default) | **Fresh context**

**If `MATRIX=false`:** `⏭ Step 1b: Oracle Gate skipped — not a Matrix feature.` Set `ORACLE_FILE = none`, log
`oracle-gate → skipped (no Matrix feature)`.

**If `MATRIX=true`:** first build the spec draft from the bundled Matrix OpenAPI (no LLM):
```bash
python3 skills/nebu-pipeline/scripts/spec_extract.py --story [STORY_FILE] --out $STEP_RESULTS_DIR/[STORY_ID]/oracle-context.md
```
Digest: `COVERAGE: full|partial|none`, `ENDPOINTS: matched=N unmatched=N`, `UNMATCHED`, `EVENT_TYPES`.

- **`COVERAGE: full`** (every endpoint of the story found, no event types / sync / e2ee concepts the OpenAPI cannot answer) and `ORACLE_LLM` is `auto` (default):
  the draft **is** the Oracle context — no agent run. Set `ORACLE_FILE = $STEP_RESULTS_DIR/[STORY_ID]/oracle-context.md`, log
  `oracle-gate → spec context from script (full coverage, N endpoints)`, show `✓ Step 1b: Oracle context generated by script (no LLM).`
- **`partial` / `none`, or `ORACLE_LLM: always`:** launch `@nebu-oracle` with the draft as head start:
```
STORY_FILE: [STORY_FILE]
REPORT_FILE: $STEP_RESULTS_DIR/[STORY_ID]/oracle-context.md
SPEC_DRAFT_FILE: $STEP_RESULTS_DIR/[STORY_ID]/oracle-draft.md
```
  Before launching: `mv $STEP_RESULTS_DIR/[STORY_ID]/oracle-context.md $STEP_RESULTS_DIR/[STORY_ID]/oracle-draft.md`. The agent keeps the draft's endpoint facts, adds
  only what it lacks (event types, behavioural rules, unmatched endpoints) and writes the final list to `REPORT_FILE`. It replies `VERDICT: DONE` + `REPORT:`.
  Set `ORACLE_FILE = $STEP_RESULTS_DIR/[STORY_ID]/oracle-context.md`; do not read or paste its content.

```bash
python3 skills/nebu-pipeline/scripts/pipeline_state.py \
  --file $STATE_FILE \
  --log "[STORY_ID] TIMESTAMP oracle-gate → spec context captured"
```

Show: `✓ Step 1b: Oracle consulted — Matrix spec context captured.`
