Verified clean: session fixation/auth bypass (new cookie per callback, old sessions deleted in one transaction, SQL timeouts, deactivation re-check, browser session never authenticates /_matrix/*), callback state confusion (`o2.acct.` before `o2.`, regexes disjoint, atomic consume, binding check), no user enumeration/provisioning, no open redirect, XSS (Phoenix.HTML.Engine everywhere), clickjacking/CSP/headers on all pages, CSRF (token, Origin, Sec-Fetch-Site, SameSite=Lax, before freshness, PRG), IDOR, reset abuse (binding to user + device + SHA-256 of supplied keys, single use, consume + key write one transaction, TTL), logging law, JsonBody/RequestLogger scoping.
