# Security Review: legacy-sso-redirect-confirmation (SEC Gate 1, closes epic SEC gate 3 G3-3), 2026-10-13

Reviewer: Kassandra (nebu-kassandra), read-only; report stored by the orchestrator. Scope: the staged diff of story `docs/stories/oauth-broker/legacy-sso-redirect-confirmation.md` (SsoRedirect classification, SsoConfirm / SsoConfirmPage, Nebu.Web.ArmScript, SsoStore `:confirm` tag, SsoLogin callback branch + D20, `Nebu.OAuth.trusted_redirect_origin?/1`, OidcConfig key, admin form, migration 000048, router / JsonBody / RequestLogger skips).

**Classification (cycle 0): CLEAN: 0 CRITICAL, 0 HIGH, 2 MEDIUM, 3 LOW, 5 INFO. Gate 1: APPROVED (not blocking); both MEDIUM and the actionable LOW items are fixed in review cycle 1 (see the story Dev Agent Record).**

## Verdict on the original attack
`redirectUrl=https://evil` + a silent IdP login no longer yields a loginToken at evil: exactly one mint path per target class (`finish_legacy_login/5` for `:direct` / listed targets, `SsoConfirm` Continue otherwise); UIA fallback and `o2.` states branch off earlier (a client-supplied `https://uia.local/complete` is an ordinary unlisted target); state replay gets 400 (pop before the IdP exchange); a second flow overwriting the cookie makes the old page's POST fail (CSRF derived from the cookie); no confirm fixation (256-bit server-generated cookie, HttpOnly, never in a URL); a direct POST needs cookie + derived CSRF (SameSite=Lax + Origin / Sec-Fetch); the 303 `Location` is the stored string that passed `classify/1`, and the displayed origin, the CSP `form-action` and the stored value come from one parse (no differential). Fuzzing `classify/1` (about 45 rows beyond the story table: backslash, userinfo incl. `:443@`, `%` and U+3002 in the authority, trailing dot, `;` `,` `&` quotes in the host, `+443`, `:0`, `:65536`, empty port, `https:////evil`, every non-canonical numeric host) found no bypass.

## Delta re-check after review cycle 1 (Kassandra, read-only, 2026-10-13)

**Classification: CLEAN (0 CRITICAL, 0 HIGH, 0 MEDIUM, 2 LOW, 3 INFO).** #1 FIXED (`trusted_redirect_url?/2`: one parse for origin and URL, registered URI equal or extended at `/ ? #`, case-sensitive path, dot segments and `%2e %2f %5c` never match, `jsonb_array_elements_text` query with LIKE escaping, 500 ms bound, fail closed; a registered URI with path `/` trusts its whole origin: the normal SPA case, INFO-1); #2 FIXED (every SsoStore call goes through `call/2` with `catch :exit`, all callers handle `{:error, :unavailable}`, no CaseClauseError path, timeout seam compile-guarded); #3 follow-up `co`; #4 PARTIAL (keyboard needs a `focusin` on Continue after arming; `form="sso-confirm-armed"` detaches Continue from its form until armed, so no-JS or a failed script fails closed; touch residual `cp`); #5 NOT FIXED in production (audit action missing from `@known_actions`; stub-writer tests) -> fixed in cycle 2; #9 FIXED. The relaxed Origin rule (Host-derived origin OR `https://<server_name>` OR `Sec-Fetch-Site: same-origin`) is SAFE: a cross-site browser POST sends `Sec-Fetch-Site: cross-site` and is refused by the lenient fetch-metadata check; old browsers must still send a matching Origin; non-browser forgers lack the HttpOnly cookie and the derived CSRF token.
New: LOW-1 = #5 above (fixed cycle 2); LOW-2 an opener can fragment-navigate the popup (no COOP by design) and cause `scroll` / hover changes that arm Continue without a real pointer movement (defence in depth only: CSRF and single use stay): fixed in cycle 2 (`scroll` no longer arms, `entered` only from a real `pointermove` with changed coordinates on Continue after arming, `hashchange` resets the button, stale timers cancelled); INFO-2 host prefix match `https://<host>%` also matched `https://<host>.other` and LIMIT without ORDER BY: fixed in cycle 2 (end or `/ : ? #`, ORDER BY); INFO-3 `redirect_with_login_token` ignored the `put_login_token` result: cycle 2 answers 503 `M_UNAVAILABLE` for an unavailable store (`:store_full` behaviour unchanged) and `SsoStore.call/2` logs one throttled tag-only WARNING when it swallows an exit.
