## Verified clean
IDOR / identical device_id on two users: delivery, ack, `pending?`, purge, txn scope, eviction 1-3, `star_devices`, wake (`user:<id>`), erasure all filter by `user_id`; a forged `since` suffix can only ack the caller's own already-delivered rows on its authenticated device; a foreign core token falls back to `ack=nil`. Spoofing/injection: `sender` from `current_user`, `type` checked with `\A..\z`, content canonicalised by Jason on write and decoded on read (nothing splices into /sync JSON). Oracles: responses look the same, statement count independent of the recipient, non-co-members get empty arrays before any query that could tell whether the user exists. Inactive/erased recipients skipped. GDPR: received and sent messages and txn records erased under the exclusive lock; runbook and 07-deployment SQL complete; no FK between the tables. Logging: only error kinds and counts; `to_device_shape?` decodes and drops empty segments; RouteNormalizer anchor; Repo `log: false`; gate call payload only user id and pid. Pre-auth: authenticate, per-user rate limit, slot, then the 64 KiB parse; JsonBody skips on decoded segments. Txn after logout: bearer revoked -> 401.
